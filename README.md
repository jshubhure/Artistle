# Artistle

**Description**

Artistle is a Wordle-style music guessing game where users try to identify a mystery artist based on attributes like country, artist type (solo or group), and year of birth. It was made with Swift, SwiftUI, and the MusicBrainz API.

**Features**

Guess the mystery artist by submitting any artist name.
Color-coded hint tiles show how close your guess is: green for a match, red for no match, and yellow for a close year.
The debut year arrows (↑ ↓) indicate if the mystery artist was born earlier or later.
A start screen explains the rules before jumping into the game.
Win or lose screen reveals the mystery artist and your guess count.

**Future Iterations**

- A daily artist mode where everyone gets the same mystery artist each day
- Autocomplete suggestions as the user types an artist name
- Expanded attributes like number of members, record label, gender, or Grammy wins
- A stats screen tracking win streak, average guesses, and guess distribution
